# 图像创作

AI 生成医学相关图像，为教学和研究提供视觉素材。

## 功能说明

图像创作模块利用 AI 图像生成能力，根据文字描述生成医学相关图像，适用于教学插图、病例配图、解剖示意等场景。

## 使用步骤

图像创作包含三个标签页：**患者头像**、**故事插图**、**自定义生成**。

### 1. 患者头像

根据当前病例与故事生成患者肖像，作为后续故事插图的参考图。生成后可在该标签页用现有提示词重新生成。

### 2. 故事插图（三步生成）

生成插图前**必须先生成患者头像**，否则系统会提示先到「患者头像」标签页生成。这是为了保证 4 张插图中的患者形象与头像一致。

点击「生成故事插图」后，系统按三步串行生成：

1. **关键情节描述** — 参考故事生成 4 段按时间线推进的情节描述文字，每段都呈现多人互动过程与疾病对患者的影响
2. **文生图提示词** — 针对每段描述单独生成一条详尽提示词，覆盖人物、场景、构图、动作互动、疾病表现、光影色彩与风格氛围
3. **生成图片** — 用 4 条提示词逐张生成插图，每张都以患者头像为参考图，生成一张显示一张

提示词区会分区展示「关键情节描述」与「文生图提示词」，可分别查看与复制；每张图片下方也保留该图实际使用的提示词。

### 3. 自定义生成

| 参数       | 说明                                                 |
| ---------- | ---------------------------------------------------- |
| **提示词** | 描述需要生成的图像内容（支持中文和英文）             |
| **风格**   | 选择图像风格（真实照片风格、医学插画风格、示意图等） |
| **尺寸**   | 图像分辨率                                           |

输入提示词后点击「生成图像」即可。

### 4. 查看与操作

生成完成后可以：

- **查看** — 查看生成的图像
- **下载** — 保存图像到本地
- **复制提示词** — 复制中间描述或最终提示词
- **重新生成** — 调整提示词后重新生成

## 提示词技巧

- **具体清晰**：描述主题、动作、环境、构图等要素
- **医学风格**：添加 "medical diagram"、"anatomical illustration" 等关键词
- **参考案例**：
  - ✓ "心脏解剖示意图，显示四个腔室和主要血管，医学插画风格"
  - ✓ "肺部 CT 影像，显示右上叶结节，带有标注"
