# 生成病例

AI 自动生成符合执业医师考试标准的完整结构化病例，是 CSTAR 教学闭环的起点。

## 功能说明

生成病例模块利用大语言模型的医学知识，生成真实感强的临床病例。每个病例包含完整的结构化信息，适用于临床教学和自主学习。生成后可对病例内容进行**校验**和**更正**，确保内容的医学严谨性。

## 使用步骤

### 1. 配置参数

在右侧设置面板中配置以下参数，设置面板包含四个标签页：

| 标签页 | 说明 |
|--------|------|
| **教科书** | 选择教科书目录层级（教科书→篇目→章节→节次→子节→主题），支持逐级选择和随机化 |
| **自定义** | 输入自定义关键词，或从预置临床维度中选择后添加 |
| **模型** | 选择用于生成的 AI 模型 |
| **提示词** | 自定义或选择生成/校验/修复的提示词模板 |

临床参数（年龄、性别、既往史、就诊场景等）通过**自定义**标签页的预置维度选择传入，或直接在输入框中输入。

#### 内容来源

生成病例的材料来源于以下两种方式：

##### 教科书内容

按照教科书目录层次结构，可以手动或者随机选择 **教科书 → 篇目 → 章节 → 节次 → 子节 → 主题**。当前可用的教科书如下：

|  教科书  | 出版时间 | 版次 | 大小 |
| :------: | :------: | :--: | :--: |
|  外科学  | 2024.07  |  10  | 27KB |
|  内科学  | 2024.07  |  10  | 17KB |
| 妇产科学 | 2024.06  |  10  | 8KB  |
|  儿科学  | 2024.06  |  10  | 13KB |
| 神经病学 | 2024.07  |  9   | 13KB |

如需自定义教科书，请参考[自定义教科书](/docs/development/custom-textbook)。

##### 自定义内容

- 在输入框内输入自定义内容，并按回车确认，可添加多个自定义内容
- 已按临床维度预置多项内容，可在选择框选择单项或多项后，点击添加

当前支持的预置维度：

| 维度 | 可选项 | 临床意义 |
|------|--------|---------|
| **年龄** | 儿童 / 青年 / 中年 / 老年 | 基础人口学，决定疾病谱筛选范围 |
| **性别** | 男性 / 女性 | 影响性别特异性疾病的纳入 |
| **既往史** | 高血压 / 糖尿病 / 冠心病 / 肝炎 / 结核病 / 哮喘 / 慢性肾病 / 脑血管病 / 消化道溃疡 | 合并症鉴别，影响诊疗方案 |
| **手术外伤史** | 无特殊 / 腹部手术史 / 骨科手术史 / 颅脑手术史 / 外伤史 | 既往手术史对病情评估的影响 |
| **过敏史** | 无 / 青霉素过敏 / 磺胺过敏 / 头孢过敏 | 药物选择的关键约束 |
| **婚育史** | 未婚 / 已婚 / 妊娠期 / 产后 / 哺乳期 / 已育 / 流产史 / 绝经 | 妇产科及泌尿科案例必需参数 |
| **生活习惯** | 吸烟 / 饮酒 / 久坐少动 / 高盐饮食 / 熬夜 / 体力劳动 | 生活方式病的病因归因 |
| **家族史** | 无特殊 / 高血压家族史 / 糖尿病家族史 / 肿瘤家族史 / 心脏病家族史 | 遗传倾向与家族聚集性疾病 |
| **就诊场景** | 门诊 / 急诊 / 住院 / 体检发现 | 决定病历书写格式与侧重点 |
| **病程特点** | 急性起病 / 慢性病程 / 进行性加重 / 反复发作 / 隐匿起病 | 决定现病史叙述结构 |
| **职业** | 学生 / 白领 / 工人 / 农民 / 退休 / 无业 | 职业相关疾病与环境暴露 |

### 2. 生成病例

点击生成按钮，AI 将根据配置参数生成完整的结构化病例，包含以下字段：

- 姓名
- 性别
- 年龄
- 主诉
- 现病史
- 既往史
- 查体
- 专科查体
- 辅助检查
- 诊断
- 治疗
- 手术
- 病理

### 3. 查看与操作

生成完成后可以：

- **查看** — 浏览完整的病例内容
- **复制** — 一键复制病例内容到剪贴板
- **重新生成** — 调整参数后重新生成
- **编辑** — 直接修改病例中的任意字段

### 4. 校验病历

生成病例后，点击工具栏的 **校验** 按钮（✓ 图标），AI 将对病例内容进行逐项医学合理性审查，包括：

- 年龄与疾病流行病学是否匹配
- 症状与诊断是否一致
- 时间线是否自洽
- 体征与检查结果是否对应
- 治疗方案是否符合临床指南
- 病理结果是否与诊断吻合

校验报告包含以下内容：

- **逐项分析** — 每项内容独立评价（合理 / 需注意 / 不合理）
- **问题汇总** — 列出所有需关注的问题点
- **校验结论** — 通过 / 需修改 / 不通过

> **自动校验**：在设置面板中开启"生成后自动校验"（autoVerify）后，病例生成完成将自动执行校验流程，无需手动点击。

### 5. 更正内容

若校验发现问题（结论为"需修改"或"不通过"），支持两种更正方式：

#### 自动更改

点击校验面板底部的 **自动更改** 按钮，AI 将根据校验报告自动修正不合理字段，保留合理的部分不变。更正过程中可实时查看 AI 的推理过程。

#### 手动更正

点击 **手动更正** 按钮，直接进入编辑模式手动修改病例内容。适合需要对特定字段进行精细调整的场景。

### 6. 复检

更正后可再次点击 **校验** 确认修改后的病例是否已满足要求，确保内容严谨可靠。

> **自动修复流水线**：同时开启"生成后自动校验"（autoVerify）和"自动修复"（autoFix）后，系统将自动执行生成→校验→修复→复检的完整闭环：生成完成后自动校验，校验未通过（结论为"需修改"或"不通过"）时自动根据校验报告修正问题字段，修正后再次自动校验确认，无需手动干预。

## 最佳实践

- **由简到繁**：初学者建议从单一诊断开始，逐步尝试复杂病例
- **贴近教学**：根据实际教学需求设定科室和诊断类型
- **用于考核**：生成的病例可直接用于后续的理论考核和互动实践环节
- **校验复检**：每次修改后建议重新校验，确保内容严谨可靠
- **自动+手动结合**：先用自动更改处理明显问题，再手动微调细节
