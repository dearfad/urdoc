# 编写故事

基于病例创作医疗叙事故事，体现叙事医学理念，培养同理心与人文关怀。

## 功能说明

叙事医学强调通过理解患者的疾病经历来提升临床能力。本模块基于已生成的病例，AI 自动创作以患者为主线的医疗叙事故事。

## 使用步骤

### 1. 准备病例

需要一个已生成的病例作为故事基础。你可以：

- **使用当前病例** — 如果已在该会话中生成病例，可直接使用
- **导入已有病例** — 从历史记录中选择

### 2. 配置参数

在右侧设置面板中配置以下参数：

| 参数 | 说明 |
|------|------|
| **叙事视角** | 患者视角、医生视角或第三人称视角 |
| **故事风格** | 专业纪实、文学叙事、医患对话等 |
| **篇幅** | 短篇、中篇或长篇 |

#### 自定义内容

- 在输入框内输入自定义内容，并按回车确认，可添加多个自定义内容
- 已按叙事维度预置多项内容，可在选择框选择单项或多项后，点击添加

当前支持的预置维度：

| 维度 | 可选项 | 作用 |
|------|--------|------|
| **题材风格** | 现实主义 / 都市情感 / 历史传奇 / 悬疑推理 / 科幻未来 / 奇幻玄幻 / 武侠江湖 / 修仙仙侠 / 穿越重生 / 恐怖惊悚 / 末世危机 / 游戏系统 | 设定整体框架与读者预期 |
| **时代背景** | 古代 / 近现代 / 当代 / 近未来 / 远古神话 / 架空世界 | 决定故事时间坐标和历史氛围 |
| **地域场景** | 三甲医院 / 社区诊所 / 乡村卫生室 / 海外医疗 / 抗疫前线 / 校园医务室 / 家庭病房 / 事故现场 | 决定故事发生的物理空间 |
| **叙事视角** | 第一人称（医生）/ 第一人称（患者）/ 第一人称（家属）/ 第三人称（全知）/ 第三人称（限知）/ 书信体 / 日记体 / 多视角交替 | 决定叙述者身份和信息量 |
| **故事基调** | 温暖治愈 / 悲伤哀婉 / 紧张悬疑 / 幽默诙谐 / 深沉哲思 / 励志向上 | 控制全文情感色彩和语言风格 |
| **人物设定** | 住院医师 / 主治医师 / 科室主任 / 实习医生 / 护士 / 慢病患者 / 急症患者 / 老年患者 / 儿童患者 / 患者家属 / 乡村医生 / 医学生 | 确定主角身份背景和代入感 |
| **情感主题** | 医患信任 / 生死抉择 / 职业理想 / 家庭羁绊 / 生命尊严 / 人性救赎 / 代际传承 / 医学伦理 | 指向故事要传递的核心价值 |
| **写作手法** | 倒叙 / 插叙 / 多线叙事 / 意识流 / 写实白描 / 象征隐喻 / 对话驱动 | 调整叙事结构和时间线组织 |
| **结局取向** | 圆满结局 / 开放结局 / 悲剧结局 / 反转结局 | 影响故事收束方式和余味 |
| **篇幅** | 短篇（3000字以内）/ 中篇（3000—10000字）/ 长篇（10000字以上） | 影响情节复杂度和展开深度 |

### 3. 生成故事

点击生成按钮，AI 将基于病例信息创作医疗叙事故事。故事通常包含：

- 患者的背景和症状出现过程
- 就医经历和诊疗过程
- 心理变化和情感体验
- 疾病对生活和家庭的影响
- 治疗结果和康复展望

### 4. 查看与操作

生成完成后可以查看、复制和重新生成故事内容。

## 教学应用

- 用于医学人文课程讨论
- 帮助医学生理解患者心理
- 培养共情能力和医患沟通技巧
- 作为叙事医学教学案例
